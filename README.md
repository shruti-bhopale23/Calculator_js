# Basic Calculator

A responsive basic calculator built using HTML, CSS, and JavaScript.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Input validation
* Division by zero validation
* Responsive design
* DOM manipulation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM

## How It Works

1. User enters two numbers.
2. User selects an arithmetic operator.
3. JavaScript reads the input values using the DOM.
4. The values are converted from strings to numbers.
5. `if-else`
6.  conditions perform the selected operation.
7. The result is displayed dynamically on the webpage.


## Validation

The calculator checks for empty inputs and prevents division by zero.
